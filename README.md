# 3D Print Manager

Локальное приложение для библиотеки STL/3MF и расчёта стоимости 3D-печати.

## Быстрый запуск Windows

1. Установите Python 3.11+ и Node.js 20+.
2. Распакуйте архив.
3. Дважды запустите `start_windows.bat`.
4. Скрипт сам создаст Python `.venv`, установит backend-зависимости, установит npm-пакеты, соберёт React/Vite frontend, запустит FastAPI и откроет браузер.
5. Адрес: http://127.0.0.1:8000

После первого запуска повторные старты быстрее.

## Что хранится локально

- SQLite: `data/database.sqlite`
- thumbnails: `data/thumbnails/`
- backups: `data/backups/`
- лог: `logs/app.log`

Оригинальные STL/3MF приложение не удаляет.

## Excel

В настройках можно выбрать исходный `.xlsx`. Есть предпросмотр и применение. Встроенный Excel не требуется после импорта: значения переносятся в SQLite.

В поставленном Excel используются листы:
- `🖨️ РАСЧЁТ ПЕЧАТИ`
- `📦 МАТЕРИАЛЫ`
- `⚙️ ПРИНТЕРЫ`
- `👥 КЛИЕНТЫ`

Расчётный движок находится в `backend/calculation_engine.py`.

## Формулы

Материал = вес × цена за грамм.

Электричество = мощность / 1000 × время в часах × цена кВт⋅ч.

Ресурс принтера = стоимость принтера / ресурс часов × время.

Брак учитывается коэффициентом 1 / (1 - процент брака).

Для обычного заказчика цена = себестоимость с браком × (1 + наценка / 100).

Для Ozon проценты от выручки решаются алгебраически:
(затраты + фиксированные расходы + желаемая прибыль) /
(1 - комиссия - эквайринг - налог).
